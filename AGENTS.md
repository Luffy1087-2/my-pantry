This project contains a pantry application for adding, removing and editiing the status of a particular product.
Every product has the following fields: name, description, isAvailable, isExpired.

The application is done using the last version of the .net core framework using sql server as a database and EF to access, read and  write data.

The dictories structure should be well-structured such data, clients is any, configurations if any, api,  abstract where there are the intercaces.

The front-end is presented with a beutiful and prefessionistic design with satifying the accessibility requirements.
The front-end is able to call the proper api per readding, deleting and editing data product.

the application is created in the environment of docker.
